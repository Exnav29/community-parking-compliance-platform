# Code of Conduct

We want CPCP to be a welcoming, respectful project for everyone who contributes.

**Expected:** be kind and constructive; assume good faith; give and accept feedback graciously; respect
privacy — never share anyone's personal data; keep discussion on the work.

**Not acceptable:** harassment, discrimination, personal attacks, doxxing, sexualized language or attention,
publishing others' private information, or sustained disruption.

**Enforcement:** maintainers may edit or remove comments, issues, PRs and commits that violate this code, and
may temporarily or permanently restrict participation. Report concerns privately via GitHub's
"Report content" tool or by contacting a maintainer through the repository's private security advisory
channel (see SECURITY.md). Reports are handled confidentially. Maintainers will explain decisions and allow a
response where appropriate.

This code applies in project spaces and when representing the project in public.
